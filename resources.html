Also known as version control, source control is used to keep track of changes in code and files in a program. Source control is important for collaborating with others, as it allows multiple people to work on a project at once without accidentally overriding someone else's work. Source control is also good for keeping track of what features one has added to their program, and can allow one to rollback to previous versions in case something breaks. Git is a free and open source version control system which can run on Windows, Mac, and Linux, and is widely used by developers for source control.

Git can accessed from the command line, but there exists Git clients which can provide the user with either a GUI or an enhanced command line environment.
